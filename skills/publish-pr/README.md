# Publish PR

Confirms change scope, creates a typed branch, stages and commits intentionally, pushes to GitHub, and opens a typed draft pull request with a concise summary, concrete evidence, and a risk and rollback assessment.

The skill favors explicit scope checks and avoids staging unrelated work.
